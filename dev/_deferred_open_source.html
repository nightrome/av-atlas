    Open-source code (Insights)

    Whether a paper releases its own source code. A first pass just scanned the arXiv page for a code-host link, but that over-counted badly (a spot check put it near 40% wrong: links to datasets or leaderboards, third-party baseline repos cited in passing, and a loose "code is available" text match that also caught "code is not available"). Now a language model reads each paper's arXiv page and decides whether the authors actually published code for this work. It works through the ~10k arXiv papers in batches, so coverage grows over time; every comparison (citation impact, share over time) is restricted to papers actually checked, never padded out with papers nobody looked at.
